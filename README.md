# DATA LAB — วิทยาการคำนวณ ม.5: ข้อมูลมีคุณค่า

เว็บไซต์บทเรียนภาษาไทยแบบ Responsive ใช้ HTML, CSS และ JavaScript ล้วน ไม่ต้องติดตั้ง Server, PHP หรือฐานข้อมูล

## โครงสร้างไฟล์
- `index.html` — โครงสร้างและเนื้อหาเว็บไซต์ (อยู่ที่ root)
- `style.css` — รูปแบบและการจัดวาง รองรับคอมพิวเตอร์ แท็บเล็ต และมือถือ
- `script.js` — เมนูมือถือ ขั้นตอนเรียนรู้ เครื่องคำนวณสถิติ และแบบทดสอบ 10 ข้อ
- `assets/` — โฟลเดอร์สำหรับไฟล์ประกอบ (เว้นไว้สำหรับเพิ่มภาพภายหลัง)

## เปิดทดสอบในเครื่อง
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `data-value-m5`
3. ดับเบิลคลิก `index.html` เพื่อเปิดด้วย Chrome, Edge, Firefox หรือ Safari
4. อินเทอร์เน็ตจำเป็นเฉพาะการโหลด Google Fonts; หากออฟไลน์ เว็บไซต์ยังทำงานได้โดยใช้ฟอนต์สำรอง

## เผยแพร่ด้วย GitHub Pages
1. ลงชื่อเข้าใช้ GitHub แล้วสร้าง Repository ใหม่ เช่น `data-value-m5`
2. อัปโหลดไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ โดยให้ `index.html` อยู่ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. ในส่วน **Build and deployment** เลือก **Deploy from a branch**
5. เลือก branch `main` และ folder `/ (root)` แล้วกด **Save**
6. รอ GitHub ประมวลผล จากนั้นเปิด URL ที่แสดงในหน้า Pages (โดยทั่วไปคือ `https://ชื่อผู้ใช้.github.io/data-value-m5/`)

## ฟังก์ชันที่มี
- เมนูนำทาง และเมนูย่อสำหรับมือถือ
- สลับดูขั้นตอนการเก็บและสำรวจข้อมูล 4 ขั้นตอน
- เครื่องคำนวณค่าเฉลี่ย มัธยฐาน และฐานนิยม พร้อมเพิ่ม/คืนค่าข้อมูล
- แบบทดสอบ 10 ข้อ เลือกคำตอบ ตรวจเฉลย คิดคะแนน และทำใหม่ได้
